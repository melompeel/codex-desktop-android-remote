Codex Remote Windows 管理器
==========================

日常使用
--------
1. 双击 CodexRemoteManager.exe。
2. 程序会自动启动 Bridge，并显示配对码、IP、端口和手机连接地址。
3. 手机第一次连接时输入窗口中的六位临时配对码。
4. 点击右上角关闭后，程序默认缩到系统托盘，手机连接不会中断。
5. Bridge 连续两次无响应时会自动重启；手动点击“停止”后不会自动拉起。
6. 点击“已授权设备”旁的小三角可展开列表，删除不再使用的手机授权。
7. 手机点击历史任务时，Bridge 会验证任务并请求 Codex Desktop 自动载入该对话。
8. 窗口顶部会显示 Windows 版本号和构建提交短号，用于确认当前实际运行的电脑包。
9. 程序启动后会静默检查 GitHub 新版本；也可点击“检查更新”手动查询。

软件更新
--------
- 发现新版本后点击“下载更新”，窗口内会显示下载进度。
- 下载完成后点击“打开文件位置”，先退出管理器，再解压 ZIP 并覆盖旧目录。
- 管理器只会下载本项目 Release 中的 Windows x64 压缩包，不会在 Bridge 运行时静默覆盖程序。
- 已安装的旧版如果没有此区域，需先手动升级到带更新功能的版本一次。

远程连接
--------
- 推荐在电脑和手机上登录同一个 Tailscale 账号。
- 在管理器“手机连接地址”中复制标记为 Tailscale 的地址。
- 局域网内也可以复制“局域网”地址。
- 不要把 Bridge 端口直接映射到公网。

配对和重启
----------
- 临时配对码有效期为 10 分钟。
- “换一个配对码”只影响尚未配对的设备，不会让已授权手机失效。
- 停止或重启 Bridge 也不会清除已授权手机。

自启动
------
勾选“登录 Windows 后自动启动”即可，不需要管理员权限。

目录说明
--------
- CodexRemoteManager.exe：唯一需要双击的程序。
- bridge、runtime：程序运行所需文件，请勿删除或单独移动。
